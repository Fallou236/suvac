# SUVAC

Plateforme de gestion et de suivi de la vaccination pré et post natale,
avec rappels vocaux en wolof.

Projet final du module Développement Backend — École Polytechnique de Thiès.
Encadrant : Professeur Michel Seck.

## Pile technique

Django 5 et Django REST Framework, PostgreSQL, Celery et Redis côté serveur.
React 18, TypeScript et Vite côté client. Docker Compose pour l'environnement local.
