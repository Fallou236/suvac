# Décisions d'architecture

Une fiche par décision structurante, au format `NNNN-titre-court.md`.

Chaque fiche indique : le contexte, la décision prise, les alternatives
écartées et pourquoi, puis les conséquences.

Une décision n'est jamais supprimée. Si elle est remplacée, la nouvelle
fiche la référence et l'ancienne passe au statut « remplacée ».
